# Monetization Plan

## Stage 1 — AdSense

Add ads only after real traffic and content quality exist. The app ships with an
unobtrusive `AdSlot` component (placeholder) in safe positions:

- Homepage: below the search block.
- City page: below the first useful results block.
- Footer / desktop sidebar.

Avoid popups, interstitials, and any ad shown before pharmacy results.

## Stage 2 — Featured pharmacy listings

Offer pharmacies: verified badge, logo/photo, WhatsApp button, priority display,
service tags, dashboard analytics.

Pricing ideas:

- 50 MAD/month — basic verified profile
- 100 MAD/month — enhanced profile
- 200 MAD/month — sponsored city placement

## Stage 3 — Sponsored health ads

Labs, clinics, dentists, parapharmacies, telemedicine, medical transport, home
nurses, health insurance agents.

## Stage 4 — Pharmacy dashboard SaaS

Update profile · confirm duty status · add WhatsApp · add services · see
clicks/calls/directions. Pricing: 49–199 MAD/month.
